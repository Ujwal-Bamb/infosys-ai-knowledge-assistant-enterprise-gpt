
# Infosys AI Knowledge Assistant (Enterprise GPT)

An enterprise AI knowledge assistant that enables authorized users
to search, retrieve and understand organizational documents using
Retrieval-Augmented Generation (RAG).

## Technology Stack

- Frontend: Next.js
- Frontend Hosting: Vercel
- Backend: Python and FastAPI
- Backend Hosting: Render
- Database: PostgreSQL
- Vector Database Extension: pgvector
- AI: LLM, embeddings and RAG

## User Roles

- Admin
- Employee
- Employer

## Core Features

- Secure credential-based login
- Role-based dashboards
- Admin-only document uploads
- Document parsing and processing
- Semantic and keyword search
- RAG-based question answering
- Source citations
- Access control and audit logging

## Repository Structure

- frontend: User interface
- backend: APIs, authentication and database services
- ingestion_pipeline: Document processing
- ai_workflows: AI and RAG workflows
- data: Safe sample documents
- docs: Project documentation
- tests: Application testing
- deployment: Hosting configuration

## Deployment

- Frontend: Vercel
- Backend: Render
- Database: PostgreSQL with pgvector
